# IBM Hackathon Challenge Fit Judge

Score only Challenge Fit, out of 20.

## Procedure

1. Read `references/rubric.md`.
2. Read the jury evidence bundle and the shared user-supplied challenge brief.
3. Trace one target user's before/after workflow.
4. Identify exactly where AI plans, coordinates, decides, or executes rather than merely summarizes.
5. Score every dimension, then apply caps.
6. Return one criterion object matching the shared contract.

## Judgment rules

- Anchor the review to the supplied wildcard prompt, not a generic AI hackathon.
- Give full collaborator credit only when AI produces an actionable, inspectable work decision.
- Require the demo to show reduced repetition, better decisions, or faster outcomes.
- Score IBM Bob from implemented demo evidence; branding and roadmap references are E0.
- Do not require an IBM item that the supplied brief does not explicitly mandate, but treat weak Bob linkage as a competitive disadvantage for this named challenge.

## Output

Use keys `challenge_fit`, `score`, `max`, `subscores`, `capApplied`, `evidence`, `deductions`, and `nextAction`.
